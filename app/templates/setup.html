4 · MacroDroid — admin siren

Admin

A push notification is still just a notification. On a dedicated admin handset, MacroDroid can force the alarm stream to full volume, play a siren on a loop and wake the screen. Staff phones do not need this — the app already runs its own full-screen alarm.

Install MacroDroid and create a macro

Play Store → MacroDroid. Add Macro → name it AlertBot Alarm.

Trigger: Connectivity → Webhook (URL)

MacroDroid shows you a URL like https://trigger.macrodroid.com/<device-id>/alertbot. Copy it into the box below.

Actions: make noise

Add these actions, in order:

Volume → Set Alarm volume to 100%
Media  → Play Sound (pick a siren) · loop = on
Device → Vibrate (long pattern)
Screen → Turn Screen On
Notification → Display Notification
    title:   AlertBot: {mv=title}
    message: {mv=message}

AlertBot sends title, message, service, provider, severity, state, event, level, incident and alarm as webhook variables — declare the ones you want as magic text in MacroDroid.

Stop the siren when you acknowledge

Add a second macro triggered by the same webhook name with alarm=0, whose action is Stop Sound. AlertBot sends alarm=0 on recovery notifications.

5 · WhatsApp chats → incidents

Admin
Manage watched chats
WhatsApp has no official way to read chats you are already in. So one admin handset does the reading: MacroDroid watches the WhatsApp notification for the chats you list, and forwards it to AlertBot. Nothing is linked to a WhatsApp account, no third-party service sees the messages, and no engineer's own phone is involved.

List the chats in Settings

Add the exact chat titles as WhatsApp shows them. Partial titles match, so "Ops Team" also catches "Ops Team (3 messages)".

New macro: AlertBot WhatsApp

Trigger → Device Events → Notification → Notification Received.

Application: pick WhatsApp Business (com.whatsapp.w4b) — it is a separate app from WhatsApp (com.whatsapp) and MacroDroid lists them separately. If the chats you watch live in both apps, tick both in the same trigger.

Leave the text filter empty — AlertBot decides which chats matter, so you edit the list in one place instead of rebuilding the macro.

MacroDroid needs notification access: it will prompt the first time. Also make sure WhatsApp Business notifications for these chats are not muted, otherwise there is no notification for the macro to see.

6 · Install this dashboard as a web app

This dashboard is a PWA, so it installs on any phone without a store. It is the receipt, not the alarm — engineers get woken by the AlertBot app in section 1, not by this.

  • Android / Chrome: menu ⋮ → Add to Home screen → Install.
  • iPhone / Safari: Share → Add to Home Screen. Then open it from the home screen — web push only works in installed mode on iOS 16.4+.
  • Desktop: the install icon in the address bar.

End-to-end check

Creates a real incident through IncidentService — the same path a Pingdom email takes. Every signed-in phone should react within a couple of seconds, and keep re-alerting until someone acknowledges it.
