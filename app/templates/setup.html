2 · MacroDroid — the real alarm

A push notification is still just a notification. MacroDroid can force the alarm stream to full volume, play a siren on a loop and wake the screen — which is what actually gets someone out of bed.

Install MacroDroid and create a macro

Play Store → MacroDroid. Add Macro → name it AlertBot Alarm.

Trigger: Connectivity → Webhook (URL)

MacroDroid shows you a URL like https://trigger.macrodroid.com/<device-id>/alertbot. Copy it into the box below.

Actions: make noise

Add these actions, in order:

Volume → Set Alarm volume to 100%
Media  → Play Sound (pick a siren) · loop = on
Device → Vibrate (long pattern)
Screen → Turn Screen On
Notification → Display Notification
    title:   AlertBot: {mv=title}
    message: {mv=message}

AlertBot sends title, message, service, provider, severity, state, event, level, incident and alarm as webhook variables — declare the ones you want as magic text in MacroDroid.

Stop the siren when you acknowledge

Add a second macro triggered by the same webhook name with alarm=0, whose action is Stop Sound. AlertBot sends alarm=0 on recovery notifications.

4 · AlertBot Android app (Firebase)

The Kotlin app lives in android/ in this repository. It receives FCM pushes, wakes the screen, plays a full-volume alarm, vibrates and lets you acknowledge the incident from the notification.

Build the APK

Your PC can't run Android Studio, so build it in the cloud: the repo ships .github/workflows/android.yml. Push to GitHub, open Actions → Build Android APK, download the artifact and install it on the Galaxy A15.

Point the app at this server

On first launch enter the backend URL and (if set) the dashboard password. The app registers its FCM token with POST /api/devices — it then shows up under Settings → devices.

Enable Firebase in Settings

Turn on the Firebase channel, then hit its Test button.

5 · Install this dashboard as an app

AlertBot is a PWA, so it installs on any phone without a store.

  • Android / Chrome: menu ⋮ → Add to Home screen → Install.
  • iPhone / Safari: Share → Add to Home Screen. Then open it from the home screen — web push only works in installed mode on iOS 16.4+.
  • Desktop: the install icon in the address bar.

End-to-end check

Creates a real incident through IncidentService — the same path a Pingdom email takes. Your phone should react within a couple of seconds, and keep re-alerting until you acknowledge it.
